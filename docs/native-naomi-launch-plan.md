Repository route reviewed offline:

- [`main_menu`](../native/netbootmenu/screens.c) sends `0x1000` with the selected four-byte index on Start release before its guest-time threshold; a longer hold enters settings. Use one deliberate brief tap, with no fixed host/guest timing claim. An accidental settings entry is a stop, not permission to save or retry.
- The [host selection handler](../sbin/piforce/dm_netboot/scripts/netdimm_menu.py) resolves the index, saves `last_game_file` to its settings file, waits 1.5 seconds, sends `0x100A` unpack progress, conditionally restores SRAM, runs `pigz -cd -p 8`, applies enabled patches and optional forced EEPROM, then sends `0x1009` with payload size/zero progress. The host subsequently sends the game with existing CRC bypass and `disable_now_loading=True`, updates scratch-register progress, reboots the NetDIMM, closes its game handle and exits in nonpersistent mode. Preserve these inherited flags; this is not the ordinary web loader/OpenFFB route. Confirm optional OpenJVS/time-hack flags remain at the previously verified off modes during fresh preflight; stop before upload if unexpected. Do not alter them to make this test pass.
- Native `game_unpack`/`game_load` render extraction/loading and observe progress/timeouts. The host unpack heartbeat is not sent through the verbose wrapper in this source; do not require it to appear as a verbose packet or infer its absence from missing verbose output. Sender completion/host exit alone cannot prove playable gameplay; host return status can also be zero after a handled send failure, so require the actual success/error log and cabinet observation.

The B2 archived installed `scripts/netdimm_menu.py` was read directly from the private backup and matched repository bytes. This supports the route above for that snapshot, not current installed identity. Fresh installed entry point/host/dependency/source hashes and invocation must still be checked before any live action.

**Refreshed count: four controlled payload phases:** installed-original baseline, candidate menu, selected game, installed-original return. The initial original upload is required because there is no host and Naomi is checking the network. Default menu sends enter NOW LOADING host mode and subsequently reboot; the selected-game send skips NOW LOADING but still reboots. Four payload phases are not a promise of four physical resets or CRT clicks. User power-on already occurred separately; no AI power/startup-setting action or retry is included.
